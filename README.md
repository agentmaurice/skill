# Maurice — plugins prêts à installer

Ce catalogue contient les connecteurs natifs, les instructions et leurs attestations. Il ne contient pas le runtime One.

Codex : `codex plugin marketplace add agentmaurice/skill --ref plugins`, puis `codex plugin add maurice@agentmaurice`.

Claude Code : `/plugin install maurice --marketplace agentmaurice/skill#plugins`.

Puis demander : **Connecte Maurice à mon One.** Indiquer son adresse et autoriser dans One. Aucun secret à copier.

Sources et documentation : https://github.com/agentmaurice/skill
